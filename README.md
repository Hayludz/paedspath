# PaedsPath

A complete paediatrics learning web app: 15 units, 130+ topics, each with structured notes, curated lecture videos, quizzes and flashcards, plus bedside calculators and quick-reference tables.

No build step, no dependencies: plain HTML, CSS and ES modules. Deploys as a static site.

## Features
- **Notes** per topic: objectives, definition to management, comparison tables, drug doses, red flags, mnemonics, exam pearls.
- **Videos** per topic, embedded and customisable: playback speed, loop, play-only clip (start/end), captions, theatre mode, floating mini-player, timestamp notes, watched/hidden flags, resume position, and add your own YouTube / Vimeo / .mp4 links.
- **Practice**: 5 single-best-answer questions per topic; mixed question bank by unit; "missed only" mode.
- **Flashcards**: 8 per topic with Leitner spaced repetition.
- **Tools**: weight/airway estimates, fluids, common doses, resuscitation drugs, WHO dehydration plans, GCS, Apgar, corrected age, BMI/BSA.
- **Investigations**: 16 categories, 34 tables of normal values by age and abnormal patterns (FBC, film, chemistry, blood gases, liver, clotting, urine, CSF, gut, endocrine, infection, immunology, ECG, chest and abdominal imaging, newborn screens), searchable, each with its own verified video playlist.
- **Reference**: vital signs, milestones, growth rules, WHO vaccine schedule, lab values.
- Search (`/` or `Ctrl K`), progress tracking, streaks, notes, bookmarks, backup/restore, light and dark themes.

Progress, notes and custom videos live in the browser's localStorage. Nothing leaves the device.

## Run locally
```bash
python -m http.server 4791
# open http://localhost:4791
```

## Maintaining content
- `data/curriculum.js` lists units and topics.
- `data/units/uNN.js` holds the teaching content (schema in `scripts/CONTENT_SPEC.md`).
- `data/videos.json` is generated by `node scripts/harvest-videos.mjs` (searches YouTube, keeps only videos that pass the oEmbed embeddability check). Re-run for topics you want refreshed; delete a topic's entry first.
- `node scripts/build-index.mjs` rebuilds the search index (`data/index.json`). Run it after editing unit content.

## Safety
Study aid only. Doses and thresholds summarise standard references (WHO, NICE, APLS, BNFc); always verify against current local guidelines.
